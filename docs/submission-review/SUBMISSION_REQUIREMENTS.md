# Final report submission requirements

Source: [Fall 2026 project assignment overview](Assignment_Overview.pdf), pages 1 and 3. This checklist summarizes the group final report requirements.

- Submit one report for the group on Gradescope by **Friday, December 11, 2026 at 11:59 p.m. ET**. The submitter should add the group members and check the receipt.
- Each member submits an individual Final Project Peer Review Form on Gradescope. The overview specifies a grade penalty for a missing form.
- Use the course Word or LaTeX template from Canvas. The group report has 8 to 10 pages of body text, excluding references and appendices. Use single spacing and 1-inch margins.
- Use numbered citations and numbered figures and tables. Place clear and readable figures and tables in the body where they are discussed.
- Connect the report to course decision-making, demonstrate critical thinking, and write professionally. Identify each member's actual technical contributions in the group report.
